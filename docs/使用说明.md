# 中文使用说明

ChatGPT 提问地图是一个 Edge 浏览器扩展，用来在一段很长的 ChatGPT 对话中快速找回之前问过的问题。

## 1. 安装

1. 在 GitHub 仓库首页点击 **Code → Download ZIP**，下载源码。
2. 将 ZIP 解压到一个准备长期保留的位置。扩展直接从这个目录运行，安装后也要保留它。
3. 在 Edge 地址栏输入 `edge://extensions` 并回车。
4. 打开「开发人员模式」。
5. 点击「加载解压缩的扩展」或「加载已解压的扩展」。
6. 选择含有 `manifest.json` 的解压目录。不要选择外层只有一个子目录的文件夹。
7. 打开或刷新 https://chatgpt.com 上的聊天页面。

网页右侧出现绿色地图按钮后即可使用。安装扩展本身不需要 Node.js、Python、API Key 或额外付费服务。

## 2. 查看和搜索提问

- 鼠标移到右侧地图上：临时展开提问目录。
- 点击地图顶部的按钮：固定展开；再次点击可收起。
- 点击目录中的问题或右侧刻度：定位到该条提问。
- 在搜索框输入关键词：只显示匹配的问题。按 Enter 跳到第一个匹配项。
- 在目录区域滚动鼠标滚轮：浏览更多条目。
- 使用底部上下箭头：在上一个、下一个匹配提问之间切换。
- 使用图钉：控制目录是否固定。

快捷键为 **Alt + Shift + M**。在目录内按 Esc 收起。在搜索框按向下方向键可进入列表，再用方向键和 Enter 选择问题。

## 3. 收录更多历史

**目录没有 7 条上限。** 如果只能看到几条，可能是目录需要滚动，也可能是 ChatGPT 当前只把最近几条消息加载到网页里。

点击目录中的 **「收录更早提问」**：

1. 扩展自动向上滚动聊天页面。
2. 网页加载出更早的提问后，扩展把它们加入目录。
3. 扫描完成后，页面回到开始扫描时的位置。
4. 扫描过程中，再次点击该按钮可停止。

特别长的对话可以再次点击，从已经收录的最早位置继续扫描。如果网页加载历史消息较慢，稍候再试。扩展只能收录网页实际提供的消息，无法保证一次扫描取得全部历史。

收录后的目录在当前标签页中保留：即使 ChatGPT 为了节省内存而卸载某些消息，地图也会继续显示它们。序号旁的小点表示该提问目前没有加载到网页中；点击后扩展会尝试回到原位置，等待网页重新加载。

工具栏菜单会区分「已收录」和「网页当前加载」两个数量。例如「已收录 42 个，网页当前加载 7 个」属于正常情况。

## 4. 保留范围

- 按当前对话分别建立目录，不把不同聊天的提问混在一起。
- 在同一个标签页切换对话，再返回时，可恢复本次打开期间已经收录的目录。
- **刷新或关闭标签页后，临时目录清空。** 重新打开后可再次收录历史。
- 修改提问、删除消息或切换对话分支后，临时目录可能仍保留先前看到的条目。刷新网页可重新建立目录。
- 本扩展用于定位用户提问，不提供跨所有历史聊天的全文搜索。

## 5. 更新

1. 下载并解压新版本。
2. 用新文件覆盖最初加载的扩展目录，保留完整文件结构。
3. 在 `edge://extensions` 找到本扩展，点击「重新加载」。
4. 刷新已经打开的 ChatGPT 页面，让新版脚本生效。

也可以先移除旧扩展，再从新的目录加载。更新到 1.1.0 时，目录中必须包含新增的 `history.js`。

## 6. 常见问题

### 页面没有地图

确认扩展已启用、当前使用的是 `chatgpt.com`，并在安装或更新后刷新网页。可从 Edge 工具栏的扩展图标打开菜单，查看开关是否开启。

### 地图显示没有提问

先确认网页中确实显示了已经发送的提问，再点击目录右上角的圆形箭头重新扫描。

如果仍为空，打开 Edge 工具栏里的本扩展，点击「查看诊断信息」，复制报告反馈即可。无需提供聊天正文。诊断会列出版本、当前域名和消息结构计数，便于检查网页结构是否变化。

### 点击历史提问没有立即跳转

早期提问可能尚未加载。扩展会先尝试滚动到之前的位置，等待网页挂载消息；如果没有成功，会显示提示。可以先点击「收录更早提问」，或手动向上滚动后再试。

### 同样的“继续”出现了多次

同一对话中可以多次发送相同文字，它们是不同的提问。地图会尽量按消息身份、顺序和位置保留这些条目。网页大幅改变布局时，定位或去重结果可能需要刷新后重新收录。

### 可以在其他浏览器使用吗

当前主要针对 Microsoft Edge 制作并测试。扩展使用 Manifest V3，可尝试在其他兼容浏览器中加载；未逐一验证兼容性。

## 7. 隐私

扩展只在 ChatGPT 对应域名工作，不上传聊天内容，不访问 Cookie 或账号令牌，也不调用内部聊天接口。

提问正文仅暂存在当前标签页内存中，不写入浏览器持久存储。扩展的本地存储只保存启用和固定目录两项偏好。自动滚动可能触发 ChatGPT 网页自身加载早期消息的网络请求。

## 8. 开发和测试

扩展不需要构建，修改文件后重新加载即可。

开发者可参照 [仓库首页的开发说明](../README.md#开发与验证) 运行语法检查和浏览器测试。自动测试使用隔离配置和模拟对话，不读取个人账号中的真实聊天。现有测试包括新版提问气泡识别、搜索跳转、120 条目录，以及「网页每次仅挂载 7 条、总计收录 42 条」的虚拟长对话场景。

本扩展是独立项目，与 OpenAI、Microsoft、DeepSeek 无隶属关系。
