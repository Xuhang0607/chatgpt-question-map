# 测试说明

测试日期：2026-10-23。

环境：本机 Microsoft Edge，无头模式，隔离测试配置，拦截 chatgpt.com 返回本地模拟对话。真实加载 Manifest V3 扩展并运行其内容脚本。

- 通过：Edge 自动加载真实扩展内容脚本
- 通过：识别全部用户提问，不包含助手回答
- 通过：打开地图与全文搜索
- 通过：跳转使用实际消息所在的嵌套滚动容器
- 通过：手动滚动同步高亮，上一问下一问可用
- 通过：新提问和编辑内容自动更新
- 通过：用户文本作为纯文本处理，图片提问有占位标题
- 通过：切换对话清除旧目录和搜索，兼容备用轮次标记
- 通过：长对话刻度有上限，完整目录保留 120 个问题
- 通过：兼容不占布局的提问容器和不同轮次标记
- 通过：用户提供的新气泡结构：无旧标记时识别、搜索、跳转及动态新增
- 通过：每次仅挂载 7 条的虚拟长对话：收录 42 条、保留、搜索与恢复定位
- 通过：切换对话后缓存独立，返回可恢复已收录历史
- 通过：新聊天生成对话地址时保留首条提问
- 通过：空对话提示、重复执行不重复注入
- 通过：快捷键、Escape 与窄窗口布局
- 通过：跟随深色主题
- 通过：工具栏菜单连接、启用开关与偏好持久化
- 通过：无页面 JavaScript 异常

截图是离线模拟对话的功能演示，不代表已在用户登录后的真实 ChatGPT 页面验证。实际网页的 DOM、懒加载及浏览器设置可能影响识别，必要时需调整选择器。
